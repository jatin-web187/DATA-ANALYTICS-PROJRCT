# 🏏 T20 World Cup Best XI Analytics

A Cricket Data Analytics project that analyzes T20 World Cup player statistics and selects the best possible Playing XI using data-driven insights.

---

# 📌 Project Overview

This project uses cricket data analytics techniques to build the strongest possible T20 team based on player performances in the T20 World Cup.

The analysis is performed using:
- Batting statistics
- Bowling statistics
- Strike rates
- Economy rates
- Consistency scores
- All-rounder contributions

The final output is a balanced and optimized Best XI team.

---

# 🚀 Features

- 📊 Player Performance Analysis
- 🏏 Best XI Team Selection
- 📈 Batting & Bowling Insights
- ⚡ All-Rounder Analysis
